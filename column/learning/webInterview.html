语义化标签的作用 ​

  1. 结构清晰：易于阅读、维护和团队协作。
  2. SEO 友好：帮助搜索引擎网络爬虫更准确地理解网页内容与结构。
  3. 无障碍访问（a11y）：屏幕阅读器等辅助技术可依此准确定位主要内容、导航、页眉或页脚。

介绍一下标准的 CSS 盒子模型？与低版本 IE 盒子模型有什么不同？ ​

两者的根本区别在于 CSS 中声明的 width 和 height 所覆盖的渲染区域不同：

  • 标准盒子模型（W3C 标准）：

    • CSS 设置的 width / height 仅包含内容区（content）。
    • 元素实际视觉宽度 = width + padding + border。
    • 页面占据总宽度 = width + padding + border + margin。

  • 低版本 IE 盒子模型（怪异盒模型）：

    • CSS 设置的 width / height 包含了内容区、内边距和边框（content + padding + border）。
    • 元素实际视觉宽度 = width（padding 和 border 向内挤压 content）。
    • 页面占据总宽度 = width + margin。

box-sizing 属性 ​

用来控制元素的盒模型解析模式：

  • content-box（默认值）：采用 W3C 标准盒子模型，设置的 width / height 仅为 content 区域。
  • border-box：采用怪异盒子模型，设置的 width / height 包含 border + padding + content。日常开发中推荐使用，元素添加 padding 和 border 不会撑大容器总尺寸。

CSS 选择器有哪些？哪些属性可以继承？ ​

  • 选择器类型：

    • id 选择器（#myid）
    • 类选择器（.myclassname）
    • 标签（元素）选择器（div, h1, p）
    • 相邻兄弟选择器（h1 + p）
    • 子选择器（ul > li）
    • 后代选择器（li a）
    • 通配符选择器（*）
    • 属性选择器（a[rel="external"]）
    • 伪类选择器（:hover, :nth-child()）
    • 伪元素选择器（::before, ::after）

  • 可继承的常见属性：

    • 文本字体类：font-size, font-family, font-weight, line-height, color
    • 文本排版类：text-align, text-indent, letter-spacing, word-spacing
    • 列表与可见性：list-style, visibility

  • 不可继承的样式：border, padding, margin, width, height, background, display, position, overflow

CSS 优先级算法如何计算？ ​

CSS 优先级使用四元组权重 (a, b, c, d) 规则进行比较（从左往右逐位比较，高位优先，不发生跨位进制）：

  1. 内联样式（style="..."）：1, 0, 0, 0（对应权重 1000）
  2. ID 选择器（#id）：0, 1, 0, 0（对应权重 100）
  3. 类选择器、属性选择器、伪类（.class, [type="text"], :hover）：0, 0, 1, 0（对应权重 10）
  4. 元素（标签）选择器、伪元素（div, p, ::before）：0, 0, 0, 1（对应权重 1）
  5. 通配符（*）、子选择符（>）、相邻兄弟符（+）：0, 0, 0, 0（无权重）

NOTE

  • !important 声明拥有最高优先级，凌驾于常规权重计算之上。
  • 同等权重下，后定义的样式覆盖先定义的样式（就近原则）。
  • 继承得到的属性权重最低（无权重，低于通配符）。

CSS3 新增常见伪类有哪些？ ​

  • :first-of-type / :last-of-type：选择属于其父元素的特定类型的首个 / 最后一个元素。
  • :only-of-type：选择属于其父元素唯一的特定类型子元素。
  • :only-child：选择属于其父元素唯一的子元素。
  • :nth-child(n) / :nth-of-type(n)：选择匹配索引的子元素。
  • :not(selector)：否定伪类，排除特定选择器。
  • :is() / :where()：现代批量组合选择器（:where 优先级恒为 0）。
  • :enabled / :disabled：表单控件的启用 / 禁用状态。
  • :checked：单选框或复选框被选中状态。

position 常见的值 ​

  1. static（默认值）：正常文档流排版，不受 top / bottom / left / right 和 z-index 影响。
  2. relative（相对定位）：相对于元素自身在普通流中的原始位置偏移，原占位空间仍保留。
  3. absolute（绝对定位）：脱离正常文档流，不占原空间，相对于最近的非 static 定位祖先元素偏移。
  4. fixed（固定定位）：脱离正常文档流，相对于浏览器视口（Viewport）定位，页面滚动时位置固定。
  5. sticky（粘性定位）：结合了 relative 和 fixed，在跨越特定阈值前表现为相对定位，之后固定在视口指定偏移位置。

typeof 操作符 ​

typeof 运算符可判断原始类型与函数，在现代 ECMAScript（ES2020+）中共返回 8 种 字符串结果： 'string', 'number', 'boolean', 'undefined', 'object', 'function', 'symbol', 'bigint'。

js
typeof "John"               // 'string'
typeof 3.14                 // 'number'
typeof NaN                  // 'number' (特殊数值)
typeof 10n                  // 'bigint' (ES2020新增)
typeof false                // 'boolean'
typeof [1, 2, 3, 4]         // 'object'
typeof { name: 'John' }     // 'object'
typeof new Date()           // 'object'
typeof function () {}       // 'function'
typeof undefined            // 'undefined'
typeof Symbol('id')         // 'symbol'
typeof null                 // 'object' (JS历史遗留 Bug，早期底层类型标签000代表对象)

清除浮动的常见方法 ​

1. 现代标准推荐：display: flow-root（最简洁标准） ​

在浮动元素的父容器上设置：

css
.father {
  display: flow-root; /* 触发无副作用的独立 BFC，自适应包含内部浮动元素 */
}

2. 父级触发 BFC（overflow: hidden） ​

css
.father {
  overflow: hidden; /* 触发 BFC 包裹内部浮动，但注意若内部有绝对定位溢出弹层可能会被裁剪 */
}

3. 父级使用 ::after 伪元素（传统主流方案） ​

css
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}

4. 额外标签法（老式做法） ​

在浮动元素末尾添加空标签 <div style="clear: both;"></div>（增加无意义 DOM，现代已不推荐）。
