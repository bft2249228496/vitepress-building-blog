JavaScript 大数值精度丢失与解决方案 ​

1. 产生原因 ​

JavaScript 的 Number 类型遵循 IEEE 754 双精度 64 位浮点数标准，能够安全精确表示的最大整数为 $2^{53} - 1$（即 Number.MAX_SAFE_INTEGER，值为 9007199254740991，约 16 位数字）。超过此安全范围的整数进行运算或赋值时，尾数位会被截断舍入，产生精度丢失。

js
const a = '12345678901234567'
const b = Number(a)
console.log(b) // 输出 12345678901234568 (最后一位失真)

2. 现代推荐解决方案：BigInt ​

现代 JavaScript（ES2020+）原生引入了 BigInt 类型，可以精确表示任意精度的超大整数（如后端 Snowflake 雪花 ID、订单号）：

js
// 1. 使用 BigInt 构造函数或字面量后缀 n
const bigNum1 = BigInt('12345678901234567')
const bigNum2 = 12345678901234567n
console.log(bigNum1.toString()) // '12345678901234567' (完全精准)

// 2. 项目接口处理
// 如果后端接口返回包含超过 16 位的 Long 类型 ID，在 JSON 经过浏览器默认 JSON.parse 时就会直接丢失精度。
// 解决办法：在 axios 请求配置中配置 transformResponse，结合 json-bigint 库进行解析。

数组的 indexOf 和 findIndex ​

  • 相同点：findIndex() 与 indexOf() 都返回数组中第一个满足条件的项的下标，若不存在均返回 -1。
  • 不同点：
    • indexOf 适用于查找原始类型的值（使用严格全等 === 比较），可指定查找起始索引 fromIndex，无法直接通过条件函数查找对象数组。
    • findIndex 接收一个回调谓词函数 (item, index, arr) => boolean，能精准比对复杂对象的属性。

解析非标伪 JSON 字符串 ​

在某些业务场景下，接口可能返回类似 '[{value1=aa, value2=bb},{value1=cc, value2=dd}]' 的非标类 JSON 字符串。

WARNING

绝不要使用 eval() 解析未知来源的字符串，这可能引发任意代码执行（XSS / 注入）安全漏洞。 正确做法是通过正则表达式将其规范化替换为标准 JSON 字符串后，再使用 JSON.parse() 解析。

js
const str = '[{value1=aa, value2=bb},{value1=cc, value2=dd}]'

// 1. 正则补齐键名的双引号: key= -> "key":
let jsonStr = str.replace(/([a-zA-Z0-9_]+)=/g, '"$1":')
// 2. 正则为非数值的值补齐双引号: :"value"
jsonStr = jsonStr.replace(/:"?([^",}\]]+)"?/g, ':"$1"')

// 3. 安全调用原生 JSON.parse
const result = JSON.parse(jsonStr)
console.log(result) // [{ value1: 'aa', value2: 'bb' }, { value1: 'cc', value2: 'dd' }]

对象数组去重的最简单方法 ​

  • 按完整对象全等去重： 将对象序列化为 JSON 字符串后利用 Set 去重，再解析回对象：
js
const uniqueArr = Array.from(new Set(arr.map((item) => JSON.stringify(item)))).map((item) => JSON.parse(item))

NOTE

注意：此方法依赖属性声明的顺序，若两个对象的键值相同但属性声明顺序不一致，JSON.stringify 得到的字符串会不同。

  • 按特定唯一属性（如 id）去重（推荐）： 利用 ES6 Map 的键唯一特性高效去重（时间复杂度 $O(n)$）：
js
const uniqueArr = [...new Map(objectArray.map((item) => [item.id, item])).values()]

方法二:

  1. 用数组的 reduce 方法。对于每个对象，将其 id 作为键，对象本身作为值，逐步累积到一个新的对象中。这个过程在初始值为空对象 {} 的基础上进行。
  2. 取这个累积后的对象的所有属性值，也就是对象的数组。
js
// 对象中的key是唯一的，如果你尝试使用相同的键向对象中添加新的值，它会自动覆盖之前的值。
const uniqueArr = Object.values(objectArray.reduce((acc, item) => ((acc[item.id] = item), acc), {}))

在谷歌浏览器页面重新发送一次 XHR 请求 ​

不用刷新页面,直接在控制台 network 中选中对应请求,右键点击,选择 replay XHR 即可

谷歌浏览器控制台 network 中自定义展示列 ​

选择任意请求,右键点击,选择 Header Options,勾选需要的列即可。 一般是在默认基础上增加 Cookies，Set Cookies 和 Waterfall 列。

谷歌浏览器控制台 network 中 Waterfall 列的使用 ​

因为 Waterfall 列默认是隐藏的，需要手动勾选。然后该列默认展示的时候是请求的耗时,正常我们需要的是请求的总耗时, 所以需要在 Header Options 中 Waterfall 列的配置中,将 Waterfall 列的单展示内容中将 Start Time 换成 Total Duration。

防抖和节流 ​

防抖和节流都是为了减少函数的调用次数,但是两者的实现方式不同。 防抖是在事件触发 n 秒后再执行回调,如果在这 n 秒内又触发了事件,则重新计时。 节流是在事件触发 n 秒后再执行回调,如果在这 n 秒内又触发了事件,则不执行回调。 通俗来讲防抖是将短时间内连续多次触发,只执行最后一次;节流是将短时间的多次执行，变成每个一段时间执行一次

js
// 防抖
function debounce(func, delay) {
  let timer
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => {
      func.apply(this, args)
    }, delay)
  }
}
// 节流
function throttle(func, delay) {
  let timer
  return function (...args) {
    if (!timer) {
      timer = setTimeout(() => {
        func.apply(this, args)
        timer = null
      }, delay)
    }
  }
}

路径中存在空格、特殊字符等，浏览器会将其转码，从而导致路径错误。空格通常会被替换为%20 或者加号（+）

import screenfull from 'screenfull'

const toggleFullscreen = () => {

  1. 模拟 F11 按键

const simulateF11 = () => {

const fullScreen = () => {

for 循环 ​

JavaScript 的 for 循环非常灵活，甚至可以省略其中一个或多个部分（但分号必须保留）。例如：

  • 省略初始化： for (; i < 10; i++)
  • 省略条件： for (let i = 0; ; i++)
  • 省略更新： for (let i = 0; i < 10; )
  • 全部省略： for (;😉 { ... } （无限循环，需要循环体内有 break 等结束条件）

全屏显示与取消全屏 ​

全屏显示用到 document.documentElement.requestFullscreen(),取消全屏用到 document.exitFullscreen()

js
const toggleFullScreen = () => {
  if (document.fullscreenElement) {
    if (document.exitFullscreen) {
      document.exitFullscreen()
    }
  } else {
    document.documentElement.requestFullscreen().catch((error) => {
      console.error('Error attempting to enable fullscreen:', error)
    })
  }
}

一个递归方法，根据传入的值来查询树状数组属性相等的对应项 ​

js
interface TreeNode {
  id: number;
  name: string;       // 想要匹配的属性
  children?: TreeNode[];
}

function findNodeByProp(tree: TreeNode[], key: keyof TreeNode, value: TreeNode[keyof TreeNode]): TreeNode | null {
  for (const node of tree) {
    if (node[key] === value) return node

    if (node.children?.length) {
      const found = findNodeByProp(node.children, key, value)
      if (found) return found
    }
  }
  return null
}

几种 for 循环的不同效果 ​

js
var head = createDoublyLinkedList([1, 2, 3, 4, 5])
/* 不完整打印 */
// 1.先处理再移动，打印结果为 1 2 3 4
for (let p = head; p.next !== null; p = p.next) {
  console.log(p.val)
}
// 2.先移动再处理，打印结果为 2 3 4 5
for (let p = head; p.next !== null; ) {
  p = p.next
  console.log(p.val)
}
/* 不完整打印 */
/* 完整打印 */
// 3.先处理再移动，打印结果为 1 2 3 4 5 （最常用）
for (let p = head; p !== null; p = p.next) {
  console.log(p.val)
}
// 4.先移动再处理，打印结果为 1 2 3 4 5
for (let p = head; p !== null; ) {
  console.log(p.val)
  p = p.next
}
/* 完整打印 */

for 循环的基本逻辑 ​

  1. 初始化：在循环开始之前执行一次，通常用于初始化变量。
  2. 条件判断：在每次循环开始前执行，用于判断是否继续循环。
  3. 更新：在每次循环结束后执行，通常用于更新循环变量。
  4. 循环体：在每次循环中执行的代码块(条件为真时执行)。
js
for (初始化; 条件判断; 更新) {
  循环体
}

new 关键字 ​

判断是否应该 new，看函数是否以构建对象为目的。不是构造函数的函数千万不要 new —— 虽然语法允许，但 this 会变，语义会坏。

应该 new 的函数 ​

  • 函数内部使用 this 去定义属性
  • 语义上是“构造对象”

不该 new 的函数 ​

  • 回值用于计算（sum, formatDate 等）
  • 不使用 this
  • 箭头函数（无法 new）
  • class 方法（无法 new）
  • React 组件函数（不应该 new）
