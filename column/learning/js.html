js 中大数值精度丢失 ​

数值超过 16 位后会精度丢失,此时无论是直接打印还是调用 Number()，值都会发生改变导致不准确。代码示例:

js
const a = '12345678901234567'
const b = Number(a)
console.log(b) //b=12345678901234568
const c = 12345678901234565
console.log(c) //c=12345678901234564

数组的 indexOf 和 findIndex ​

相同点:findIndex()与 indexOf()都是返回数组中第一个满足条件的项的下标,如果不存在返回-1 不同点:findIndex 比 indexOf 更强大一些，可以通过回调函数查找对象数组，indexOf 只能查找数组中指定的值，不过 indexOf 可以指定开始查找位置的索引

解析复杂字符串 ​

如'[{value1=aa, value2=bb},{value1=cc, value2=dd}]'这种有规律但又不完全符合 JSON 字符串格式的字符串.如果想要转成对象需要找规律进行字符串替换,然后使用 eval 方法。(此处使用 JSON.parse 会报错, 使用 JSON.parse(JSON.stringify())不生效)

js
// 1.找规律通过字符串替换
// 2.使用eval('(' + str + ')')转换(此处使用JSON.parse会报错, 使用JSON.parse(JSON.stringify())不生效)
const str = '[{value1=aa, value2=bb},{value1=cc, value2=dd}]'
const tempStr = str?.replaceAll('=', ':"')
const tempStr1 = tempStr.replaceAll(',', '",')
const tempStr2 = tempStr1.replaceAll('}"', '"}')
const newStr = tempStr2.replaceAll('}]', '"}]')
const arr = eval('(' + newStr + ')')

对象数组去重的最简单方法 ​

  • 对于对象数组不同项的键和值完全相同认为重复: 使用 map 方法遍历数组,将数组的每一项转成 JSON 字符串,再使用 set 去重,再使用 Array.from 转回数组,再使用 map 方法遍历数组,将数组的每一项转为 JSON 对象
js
const uniqueArr = Array.from(new Set(arr.map((item: any) => JSON.stringify(item)))).map((item: any) => JSON.parse(item))
  • 对于对象数组不同项的某个键的值(即某个属性相同)认为重复: 方法一:
  1. 使用 map 方法，对 objectArray 数组中的每个对象执行一个映射操作。对于每个对象，这里创建了一个包含 id 属性和对象本身的数组。
  2. 将上一步得到的数组转换为 Map 对象。在这个步骤中，使用数组中的 id 作为键，对象本身作为值，创建了一个新的 Map 对象。
  3. 从 Map 对象中获取所有的 values（值），并使用扩展运算符将它们转换为一个数组。
js
// Map 对象中的 key 是唯一的，如果你尝试使用相同的键向 Map 对象中添加新的值，它会自动覆盖之前的值。
const uniqueArr = [...new Map(objectArray.map((item) => [item.id, item])).values()]

方法二:

  1. 用数组的 reduce 方法。对于每个对象，将其 id 作为键，对象本身作为值，逐步累积到一个新的对象中。这个过程在初始值为空对象 {} 的基础上进行。
  2. 取这个累积后的对象的所有属性值，也就是对象的数组。
js
// 对象中的key是唯一的，如果你尝试使用相同的键向对象中添加新的值，它会自动覆盖之前的值。
const uniqueArr = Object.values(objectArray.reduce((acc, item) => ((acc[item.id] = item), acc), {}))

不用刷新页面,直接在控制台 network 中选中对应请求,右键点击,选择 replay XHR 即可

选择任意请求,右键点击,选择 Header Options,勾选需要的列即可。 一般是在默认基础上增加 Cookies，Set Cookies 和 Waterfall 列。

谷歌浏览器控制台 network 中 Waterfall 列的使用 ​

因为 Waterfall 列默认是隐藏的，需要手动勾选。然后该列默认展示的时候是请求的耗时,正常我们需要的是请求的总耗时, 所以需要在 Header Options 中 Waterfall 列的配置中,将 Waterfall 列的单展示内容中将 Start Time 换成 Total Duration。

防抖和节流 ​

防抖和节流都是为了减少函数的调用次数,但是两者的实现方式不同。 防抖是在事件触发 n 秒后再执行回调,如果在这 n 秒内又触发了事件,则重新计时。 节流是在事件触发 n 秒后再执行回调,如果在这 n 秒内又触发了事件,则不执行回调。 通俗来讲防抖是将短时间内连续多次触发,只执行最后一次;节流是将短时间的多次执行，变成每个一段时间执行一次

js
// 防抖
function debounce(func, delay) {
  let timer
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => {
      func.apply(this, args)
    }, delay)
  }
}
// 节流
function throttle(func, delay) {
  let timer
  return function (...args) {
    if (!timer) {
      timer = setTimeout(() => {
        func.apply(this, args)
        timer = null
      }, delay)
    }
  }
}

for 循环 ​

JavaScript 的 for 循环非常灵活，甚至可以省略其中一个或多个部分（但分号必须保留）。例如：

  • 省略初始化： for (; i < 10; i++)
  • 省略条件： for (let i = 0; ; i++)
  • 省略更新： for (let i = 0; i < 10; )
  • 全部省略： for (;😉 { ... } （无限循环，需要循环体内有 break 等结束条件）

全屏显示与取消全屏 ​

全屏显示用到 document.documentElement.requestFullscreen(),取消全屏用到 document.exitFullscreen()

js
const toggleFullScreen = () => {
  if (document.fullscreenElement) {
    if (document.exitFullscreen) {
      document.exitFullscreen()
    }
  } else {
    document.documentElement.requestFullscreen().catch((error) => {
      console.error('Error attempting to enable fullscreen:', error)
    })
  }
}

一个递归方法，根据传入的值来查询树状数组属性相等的对应项 ​

js
interface TreeNode {
  id: number;
  name: string;       // 想要匹配的属性
  children?: TreeNode[];
}

function findNodeByProp(tree: TreeNode[], key: keyof TreeNode, value: TreeNode[keyof TreeNode]): TreeNode | null {
  for (const node of tree) {
    if (node[key] === value) return node

    if (node.children?.length) {
      const found = findNodeByProp(node.children, key, value)
      if (found) return found
    }
  }
  return null
}

几种 for 循环的不同效果 ​

js
var head = createDoublyLinkedList([1, 2, 3, 4, 5])
/* 不完整打印 */
// 1.先处理再移动，打印结果为 1 2 3 4
for (let p = head; p.next !== null; p = p.next) {
  console.log(p.val)
}
// 2.先移动再处理，打印结果为 2 3 4 5
for (let p = head; p.next !== null; ) {
  p = p.next
  console.log(p.val)
}
/* 不完整打印 */
/* 完整打印 */
// 3.先处理再移动，打印结果为 1 2 3 4 5 （最常用）
for (let p = head; p !== null; p = p.next) {
  console.log(p.val)
}
// 4.先移动再处理，打印结果为 1 2 3 4 5
for (let p = head; p !== null; ) {
  console.log(p.val)
  p = p.next
}
/* 完整打印 */

for 循环的基本逻辑 ​

  1. 初始化：在循环开始之前执行一次，通常用于初始化变量。
  2. 条件判断：在每次循环开始前执行，用于判断是否继续循环。
  3. 更新：在每次循环结束后执行，通常用于更新循环变量。
  4. 循环体：在每次循环中执行的代码块(条件为真时执行)。
js
for (初始化; 条件判断; 更新) {
  循环体
}

new 关键字 ​

判断是否应该 new，看函数是否以构建对象为目的。不是构造函数的函数千万不要 new —— 虽然语法允许，但 this 会变，语义会坏。

应该 new 的函数 ​

  • 函数内部使用 this 去定义属性
  • 语义上是“构造对象”

不该 new 的函数 ​

  • 回值用于计算（sum, formatDate 等）
  • 不使用 this
  • 箭头函数（无法 new）
  • class 方法（无法 new）
  • React 组件函数（不应该 new）
