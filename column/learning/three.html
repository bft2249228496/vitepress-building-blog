创建 3d 图像的大致步骤 ​

必要步骤 ​

  1. 创建场景对象（Scene）
  2. 创建几何体对象（长方体：BoxGeometry，圆柱体：CylinderGeometry, 球体：SphereGeometry， 圆锥： ConeGeometry，矩形平面：PlaneGeometry，圆平面：CircleGeometry）
  3. 创建材质对象（网格基础材质：MeshBasicMaterial，网格漫反射材质：MeshLambertMaterial，网格高光材质：MeshPhongMaterial，物理材质：MeshStandardMaterial,MeshPhysicalMaterial,点材质：PointsMaterial，线基础材质：LineBasicMaterial，精灵材质：SpriteMaterial）
  4. 根据几何体对象和材质对象，创建物体对象（Mesh，Point）
  5. 设置物体对象的位置：position.set 方法
  6. 把物体对象加入到场景中：add 方法
  7. 创建相机对象（常用透视相机 PerspectiveCamera），第二参数为画布的宽高比，其他参数可以先用默认值（50， width/height, 0.1, 2000）
  8. 设置相机位置：position.set 方法
  9. 设置相机观察点位置：lookAt 方法
  10. 创建渲染器对象（WebGLRenderer)
  11. 设置渲染器尺寸即画布宽高：setSize 方法
  12. 将场景对象和相机对象放入渲染器渲染：render 方法
  13. 将渲染出来的渲染器对象的 domElement 插入到页面元素中：appendChild 方法
  14. 根据相机对象和渲染器的 domElement 对象创建轨道控制器对象（OrbitControls）
  15. 监听轨道控制器对象的 change 事件，每次 change 触发，执行渲染器渲染 render 方法（步骤 19 和 15 二选一执行）
  16. 创建光源对象（点光源：PointLight，平行光：DirectionalLight， 环境光：AmbientLight）
  17. 设置光源对象的位置:position.set 方法（环境光无需设置）
  18. 将光源对象添加到场景中：add 方法
  19. 渲染循环动画：requestAnimationFrame（步骤 19 和 15 二选一执行），在动画中执行控制器更新 update 方法，渲染器渲染 render 方法

可选步骤 ​

  1. 创建三维坐标轴对象（AxesHelper）
  2. 三维坐标轴对象放入场景中：add 方法
  3. 创建可视化对象 Gui，无需手动插入，直接可以使用对应的 addFolder 方法以及示例对象上的 add 方法
  4. 创建帧率查看对象 Stats
  5. 将 Stats 实例上的 domElement 对象插入 html 元素中
  6. 每次动画改变时执行 Stats 实例的 update 方法

three 开发的注意事项 ​

  1. 颜色设置为：0x + 十六进制，0x 相当于#，后续 6 位十六进制不可以缩写成 3 位（0xff0000 等效于前端的'#ff0000'）
  2. 将物体材质设置为半透明可看到坐标轴原点
  3. 三维坐标轴：红色轴对应 x 轴，绿色轴对应 y 轴，蓝色轴对应 z 轴
  4. 基础网格材质不受光照影响，其他材质都受光照影响
  5. requestAnimationFrame 的同名函数中应该执行两件事：物体的周期性变动，渲染器的周期性渲染
  6. 一旦使用了渲染循环就不再需要监听轨道控制器对象的 change 事件
  7. 窗口变化需要监听 resize 事件来处理：重新设置渲染器的尺寸，重新设置相机的宽高比，相机执行属性更新（updateProjectionMatrix）
  8. 相机位置更远能看到更多的观察范围，超出相机远裁截面的物体会被剪掉
  9. 相机的观测点为画布的正中间
  10. 轨道控制器会影响相机观测点的设置，注意手动设置回到控制器的目标参数
  11. 透视投影相机符合远小近大的投影规律
  12. 增加相机视角，视锥体范围更大
  13. 轨道控制器使用：旋转：拖动鼠标左键，缩放：滚动鼠标中键，平移：拖动鼠标右键
  14. threejs 中平面图形默认只有正面可见，通过设置材料的 side 为 THREE.DoubleSide 可实现双面可见
  15. 对渲染器添加 antialias 属性为 true 可实现抗锯齿
  16. 设置渲染器像素比为屏幕像素比：renderer.setPixelRatio(window.devicePixelRatio)
  17. gui 库可以实现可视化操作调试 three 的属性，而且 gui 不依赖 three
  18. gui 库的 add 方法可实现添加对象的属性用于可视化动态调试，name 方法可以将属性重命名，step 方法可设置步长,onChange 事件可监听属性变化，addColor 可改变颜色
  19. gui 库的 addFolder 方法可以实现分组，close 方法可以设置菜单初始为收起状态
  20. 引入使用的时候只有 THREE 本身不需要通过构造函数调用，其他的轨道控制器 OrbitControls，查看渲染帧 Stats，可视化界面 GUI 都是需要通过构造函数调用的
  21. 点模型有自己的专属材质，线模型也有自己的专属材质
  22. 线模型有三种：普通线 Line，闭合线 LineLoop, 非连续线 LineSegments
  23. 网格模型的方向：选中一个面的三个点：坐标原点为 1，x 轴的点为 2，y 轴的点为 3,1-2-3 构成的方向如果是逆时针则为正面，顺时针则为反面
  24. 所有的网格模块都可以通过缓冲类型几何体的顶点数据构建的多个三角形构成
  25. 用缓冲类型几何体构建顶点数据时必须用类型化数组，用普通 js 数组会报错
  26. 材质属性里面设置 wireframe 为 true 可以线条模式渲染
  27. 使用 clone 方法只克隆物体对象，默认会和之前的物体共用材质和几何体
  28. 任何一个模型的本地坐标（局部坐标）就是模型的 position 属性，一个模型的世界坐标是模型自身的 position 和所有父对象的 position 累加的坐标，可通过 getWorldPosition(new THREE.Vector3())
  29. translate 方法会改变模型的本地坐标原点的位置
  30. 使用纹理贴图需要关闭线条模式渲染，一般不再同时设置颜色属性
  31. 通过相机控件的缩放旋转调整相机的 position 参数，通过相机控件的平移操作调整相机的 lookAt 参数（即相机控件的 target 参数）
  32. gltf 是三维模型的标准数据格式，glb 是 gltf 文件的二进制文件格式
  33. 相机的选择：主要为透视投影相机和正投影相机，大部分情况用的是透视投影相机（符合人眼视觉）
  34. threejs 的世界没有任何单位的概念，只有数字大小的计算
  35. 解决加载 gltf 格式模型纹理贴图和原图不一致的问题：renderer.outputEncoding = THREE.sRGBEncoding
  36. traverse 方法可递归遍历所有模型的节点
  37. 共享材质问题可以通过 clone 材质方法实现每个物体材质独立渲染
  38. 查找某个具体的模型方法：getObjectByName
  39. 对于 PBR 材质，如果 threejs 三维场景不添加任何光源，也不添加环境贴图，物体就是完全黑色的（环境贴图其实也相当于提供了物体周围环境发射或反射的光线）
  40. 可以对场景的 environment 属性添加环境贴图，也可以递归遍历物体的材质的 envMap 属性添加环境贴图
  41. 引入外部模型步骤：引入加载器；new 一个加载器对象；调用加载器对象实例的 load 方法，接受两个参数，第一个是加载器路径（new URL('../assets/three/metal.glb', import.meta.url).href），第二个是一个回调函数，函数参数为当前的外部模型对象，在函数中将外部模型对象的场景对象添加到真实的组或者场景中即可
  42. 对于现实的物理材质可用透光率 transmission 代替透明度
  43. threejs 解析 gltf 模型时，会用两种 PBR 材质去解析：优先选用标准网格模型 MeshStandardMaterial,次选物理网格模型 MeshPhysicalMaterial
  44. threejs 渲染结果保存为图片：渲染器中传入参数 preserveDrawingBuffer: true,再调用 canvas 的 toDataURL('image/png')方法即可
  45. threejs 三维场景中有一些面距离比较近，会有深度冲突，可渲染器中传入参数 logarithmicDepthBuffer: true 来解决
  46. 发光描边处理：通过 EffectComposer.js 效果合成器扩展库指定渲染器，通过 RenderPass.js 渲染器通道扩展库指定相机和场景，再通过 addPass 方法给效果合成器增加渲染器通道，渲染循环动画里用 composer.render()代替 state.renderer.render(scene, camera)
  47. 带有宽度的线需要用 LineGeometry 几何体构造函数，LineMaterial 材料构造函数，以及物体构造函数 Line2 来创建，并且这三个构造函数不属于 three 基础库，需要在 node 扩展包里面分别单独引入，路径一般是 three/examples/jsm/
  48. 使用 gltf-pipeline 插件可以实现 glb、gltf、gltf + bin + jpg/png 三种格式之间的转换
  49. 使用gltf-pipeline 插件也可以压缩 gltf 模型，压缩后的文件无法直接加载, 需要使用DRACOLoader加载器解压缩

three 开发的实战案例细节 ​

随机山脉地形 ​

  1. 引入噪音算法库:simplex-noise
  2. 创建 threejs 场景
  3. 创建几何体:使用 PlaneGeometry,使用较大的宽高以及宽高分段数
  4. 创建材质:使用 MeshBasicMaterial,设置以线条方式渲染 wireframe: true
  5. 创建物体对象:使用 Mesh,传入几何体和材质
  6. 将物体绕 X 轴旋转 90°:mesh.rotateX(Math.PI / 2)
  7. 创建相机:使用 PerspectiveCamera,传入参数 fov,aspect,near,far,并设置相机位置 position 和目标 lookAt
  8. 将相机和物体对象添加到场景中
  9. 创建渲染器:使用 WebGLRenderer,设置抗锯齿 antialias: true，设置渲染器尺寸 renderer.setSize(window.innerWidth, window.innerHeight)
  10. 将渲染器添加到页面中:document.body.appendChild(renderer.domElement)
  11. 创建控制器:使用 OrbitControls,传入相机和渲染器 domElement
  12. 创建物体顶点更新函数:
js
const updatePosition = () => {
  const positions = geometry.attributes.position
  for (let i = 0; i < positions.count; i++) {
    const x = positions.getX(i)
    const y = positions.getY(i)
    // 通过噪音渲染器得到连续的随机z值
    const z = noise(x * 0.05, y * 0.05) * 10
    // 通过正弦函数和时间戳让每一次值都是根据x值和时间波动
    const sinNum = Math.sin(Date.now() * 0.002 + x * 0.05) * 10
    positions.setZ(i, sinNum + z)
  }
  positions.needsUpdate = true
}
  1. 创建动画:使用 requestAnimationFrame,传入回调函数,回调函数中更新控制器 controls.update(), 调用顶点更新函数 updatePosition,并渲染场景 renderer.render(scene, camera)
