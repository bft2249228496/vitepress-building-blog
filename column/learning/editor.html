vscode 格式化 vue 项目 vscode 格式化 vue 项目 ​

1.在项目的根目录下新建一个.prettierrc 的配置文件

js
 {
    "semi": false,
    "singleQuote": true,
    "printWidth": 200
  }

2.保存后弹出选择格式化文件提示，选择 Prettier -Code formatter

vscode 中折叠任意代码块 ​

//#region 开头，//#endregion 结尾

vscode 选中多行代码删除时会弹出提示,导致无法多行同时删除 ​

打开设置,搜索 editor.parameterHints,将 Parameter Hints:Cycle 选项取消勾选

VScode (因为在此系统上禁止运行脚本)报错 ​

命令行执行以下步骤: 执行：get-ExecutionPolicy，显示 Restricted，表示状态是禁止的; 执行：set-ExecutionPolicy 会提示输入参数：RemoteSigned

如果继续报错：提示对注册表项“HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PowerShell\1\ShellIds\Microsoft.PowerShell”的访问被拒绝： 解决方法： 方法一: 输入以下命令

sh
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

方法二:

  1. 使用“以管理员身份运行”选项启动 Windows PowerShell
  2. 输入：Set-ExecutionPolicy -Scope CurrentUser
  3. 输入:RemoteSigned
  4. 输入：Y

清空项目里所有打印代码 ​

在 vscode 中使用在文件夹中查找，正则匹配:将 console.log.*$替换为空，即可删除项目中所有的 console.log

vscode 安装离线插件的方法 ​

步骤如下: 1.进入 vscode 插件市场:https://marketplace.visualstudio.com/ 2.切换 Visual Studio Code 的选项,搜索插件名 3.点击进入，切换 Version History 可选择最近五次版本下载;或者点击右侧 Repository 进入 github 仓库点击 tags 选择更早版本下载 4.打开 vscode 应用商店,点击...,选择从 VSI 安装，选择自己刚刚下载的插件即可

vscode 编辑器顶部显示完整路径的方法 ​

打开设置-搜索：window.title-然后将最后一行的 activeEditorShort 改为 activeEditorLong

vscode 本地无法获取线上最新分支 ​

需要再对应项目的根目录下打开 git.bash,输入以下命令

sh
git remote update origin --prune

  1. Baidu Comate(文心快码-百度 AI 代码助手)
  2. TONGYI Lingma(通意灵码-阿里 AI 代码助手)
  3. MarsCode:AI Code Assistant(火星码-字节 AI 代码助手)

vscode 对 vue,react 等工程项目或者其中的 npm 进行调试 ​

  1. 打开并运行该项目,点击左侧运河调试按钮,创建 launch.json 文件
js
{
    "version": "0.2.0",
    "configurations": [
      {
        "type": "pwa-node",
        "request": "launch",
        "name": "调试npm",
        "runtimeExecutable": "npm",
        "runtimeArgs": ["run-script", "serve"],
        "skipFiles": [
          "<node_internals>/**"
        ],
        "presentation": {
          "hidden": false,
          "group": "backend",
          "order": 1
        }
      },
      {
        "type": "chrome",
        "request": "launch",
        "name": "调试vue",
        "runtimeExecutable": "stable",
        "runtimeArgs": ["--auto-oppen-devtools-for-tabs"],
        "userDataDir": true,
        "url": "http://localhost:8080",
        "presentation": {
          "hidden": false,
          "group": "frontend",
          "order": 1
        }
      }
    ]
  }
  1. launch.json 配置文件的 url 中端口号改为和项目启动端口号一致,点击开始调试即可
  2. 注意:如果提示无法启动浏览器：spawn UNKNOWN，说明 launch.json 中 runtimeExecutable 的谷歌浏览器路径不正确或者未配置，请根据实际情况修改

在 vue 项目中,可以使用日志断点代替 log ​

在需要打印的地方的断点标记处右键选择日志断点, 然后输入要打印的变量名即可。格式为 a={a},多个打印可用空格隔开。

chtml 插件 ​

方式一、alt+c 打开变量转换框，支持简繁体中文转变量、变量再转（tableName 输入转其他类型变量命名方式）、支持英文直接转变量 方式二、alt+b 直接打开 web 端的在线工具 方式三：输入中文，并选中该中文或需要转换的英文字符串，按下快捷键“alt+1”转小驼峰 1-5 分别对应：1 小驼峰(linkA)、2 大驼峰（LinkA）、3 下划线法（link_a）、4 前下划线法(_link_a)，5 转脊柱法（linkA\link_a\LINK_A=>link-b）

labuladuo 插件 ​

登录方法:

  1. 打开浏览器地址 https://leetcode.cn/problemset/,打开控制台
  2. 登录自己账号,network 面板中找到https://leetcode.cn/problemset/接口,如果没有将上面的筛选切换到 All
  3. 右键点击该接口，选择 copy as cURL(bash),打开 labuladuo 插件,粘贴该接口即可

trae 编辑器 ts 报错 ​

sh
Cannot find module '@vben/plugins/echarts' or its corresponding type declarations.

解决方案：删除 vetur 插件,换成 vue-offical 插件

trae 编辑器终端的粘滞滚动 ​

可通过调整.vscode/settings.json 文件中的 terminal.integrated.stickyScroll.enabled 设置

json
{
  "terminal.integrated.stickyScroll.enabled": true // 启用终端的粘滞滚动
}

彻底卸载 windsurf 编辑器 脚本 ​

bat
@echo off
title Uninstall WindSurf Completely
echo ======================================================
echo   WindSurf Windows 完全卸载脚本
echo ======================================================
echo.

REM ---------------------------
REM 1. 结束 Windsurf 进程
REM ---------------------------
echo [1/6] 正在结束 WindSurf 进程...
taskkill /IM windsurf.exe /F >nul 2>&1
taskkill /IM windsurf-helper.exe /F >nul 2>&1
taskkill /IM code.exe /F >nul 2>&1
echo 完成。
echo.

REM ---------------------------
REM 2. 删除程序安装目录
REM ---------------------------
echo [2/6] 删除 WindSurf 安装目录...
rmdir /S /Q "%LocalAppData%\Programs\WindSurf" 2>nul
rmdir /S /Q "%LocalAppData%\WindSurf" 2>nul
rmdir /S /Q "%ProgramFiles%\WindSurf" 2>nul
rmdir /S /Q "%ProgramFiles(x86)%\WindSurf" 2>nul
echo 完成。
echo.

REM ---------------------------
REM 3. 删除配置、缓存、全局存储
REM ---------------------------
echo [3/6] 删除 WindSurf 配置与缓存...
rmdir /S /Q "%AppData%\WindSurf" 2>nul
rmdir /S /Q "%LocalAppData%\WindSurf" 2>nul
rmdir /S /Q "%UserProfile%\.windsurf" 2>nul
rmdir /S /Q "%AppData%\Code\User\globalStorage\windsurf*" 2>nul
echo 完成。
echo.

REM ---------------------------
REM 4. 删除 VS Code / Windsurf 扩展
REM ---------------------------
echo [4/6] 删除 WindSurf 相关扩展...
rmdir /S /Q "%UserProfile%\.vscode\extensions\windsurf*" 2>nul
rmdir /S /Q "%UserProfile%\.windsurf\extensions\windsurf*" 2>nul
echo 完成。
echo.

REM ---------------------------
REM 5. 删除注册表项
REM ---------------------------
echo [5/6] 清理注册表...
reg delete "HKCU\Software\WindSurf" /f >nul 2>&1
reg delete "HKLM\Software\WindSurf" /f >nul 2>&1
reg delete "HKLM\Software\WOW6432Node\WindSurf" /f >nul 2>&1

REM 全局搜索 Windsurf 字样的残留键（可能提示找不到，正常）
for %%K in (
    "HKCU\Software"
    "HKLM\Software"
    "HKLM\Software\WOW6432Node"
) do (
    reg query %%K | findstr /I "windsurf" >nul 2>&1
    if %errorlevel%==0 (
        echo 检测到可能残留的 Windsurf 键：%%K
        echo 尝试删除...
        reg delete "%%K" /f >nul 2>&1
    )
)
echo 完成。
echo.

REM ---------------------------
REM 6. 删除背景服务（如果有）
REM ---------------------------
echo [6/6] 删除 Windsurf 服务...
sc delete windsurf >nul 2>&1
echo 完成。
echo.

echo ======================================================
echo   WindSurf 已彻底卸载（含所有残留）
echo ======================================================
pause
exit
