数组特点 ​

数据在内存中连续存储，支持根据下标快速随机访问（时间复杂度 $O(1)$）。但在非首尾位置插入或删除元素时，往往需要移动后续所有元素（时间复杂度 $O(n)$）。

链表特点 ​

由一系列通过指针（引用）连接的节点组成，元素在内存中非连续分布。

  • 优点：插入和删除节点效率高（已知前驱节点时时间复杂度为 $O(1)$），无需搬移内存。
  • 缺点：无法通过下标随机访问，必须从头指针顺次遍历查找（时间复杂度 $O(n)$）。

二叉树 ​

每个节点最多包含两棵子树（左子树与右子树）的树状结构。

  • 完全二叉树：除最底层外每一层都填满，且最底层的节点都依次紧凑集中在最左边。
  • 满二叉树：每一层的节点数都达到最大值（深度为 $k$ 且有 $2^k - 1$ 个节点）。
  • 最大深度：从根节点到最远叶子节点的最长路径上的节点数。
  • 最小深度：从根节点到最近叶子节点的最短路径上的节点数（叶子节点指没有子节点的节点）。

时间复杂度与空间复杂度 ​

时间复杂度（Time Complexity） ​

衡量算法执行时间随输入规模 $n$ 增长的渐近趋势量级（通常使用大 $O$ 符号表示最坏或渐近上界），并非代码具体执行的毫秒数或机器指令次数。

  • 加法法则：$O(f(n)) + O(g(n)) = O(\max(f(n), g(n)))$，保留增长最快的主导项。
  • 乘法法则：嵌套循环等场景满足乘法，$O(f(n)) \times O(g(n)) = O(f(n) \times g(n))$。
  • 常见量级：$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(2^n)$。

空间复杂度（Space Complexity） ​

衡量算法在运行过程中所额外占用的临时存储空间随输入规模 $n$ 增长的趋势。

  • 计算空间复杂度时，输入数据本身占用的空间不计入，只计算算法为了解决问题而额外申请的辅助内存。
  • 额外开销包括：新创建的数据结构（数组、哈希表、树等）、递归调用所占据的调用栈（Call Stack）深度。

计算机中的对数 ​

在计算机科学中，除特殊说明外，对数默认以 2 为底（即 $\log n = \log_2 n$），常见于二分查找、二叉树高度计算以及分治算法中。

Set 集合交集、并集操作 ​

1. 现代原生语法（ECMAScript 推荐） ​

现代 JS 引擎已正式原生内置 Set 集合运算方法：

js
const setA = new Set([1, 2, 3]);
const setB = new Set([2, 3, 4]);

// 交集: Set(2) { 2, 3 }
const intersection = setA.intersection(setB);

// 并集: Set(4) { 1, 2, 3, 4 }
const union = setA.union(setB);

// 差集 (A 中有但 B 中没有): Set(1) { 1 }
const difference = setA.difference(setB);

// 对称差集 (两个集合中不重复的元素): Set(2) { 1, 4 }
const symmetricDiff = setA.symmetricDifference(setB);

2. 传统兼容写法 ​

js
// 求交集：时间复杂度 O(n)
const intersection = new Set([...set1].filter(item => set2.has(item)));

栈（Stack）与队列（Queue） ​

  • 栈（Stack）：先进后出（LIFO，Last In First Out）。常见应用：函数调用栈、括号有效性匹配、浏览器历史回退。
  • 队列（Queue）：先进先出（FIFO，First In First Out）。常见应用：事件循环（Event Loop）任务队列、广度优先搜索（BFS）、请求排队缓冲。

堆（Heap） ​

堆是一种特殊的完全二叉树，在前端常用普通数组进行紧凑存储与模拟。

  • 索引映射公式：
    • 节点 i 的左子节点位置：2 * i + 1
    • 节点 i 的右子节点位置：2 * i + 2
    • 节点 i 的父节点位置：Math.floor((i - 1) / 2)
  • 堆的分类与特性：
    • 最大堆（大顶堆）：任意节点的值均 $\ge$ 其子节点的值，堆顶恒为全堆最大值。
    • 最小堆（小顶堆）：任意节点的值均 $\le$ 其子节点的值，堆顶恒为全堆最小值。
    • 获取最值的时间复杂度为 $O(1)$，插入与删除堆顶的时间复杂度为 $O(\log n)$。
  • 应用场景（Top K 问题）：
    • 求“第 K 个最大元素”：维护容量为 $K$ 的最小堆。遍历元素依次加入，容量超 $K$ 则弹出堆顶；遍历完成后堆顶即为目标值。

二叉树的遍历算法 ​

深度优先遍历（DFS） ​

优先沿着树的深度递归向下探索：

  • 先序遍历（Pre-order）：根节点 -> 左子树 -> 右子树（根左右）
  • 中序遍历（In-order）：左子树 -> 根节点 -> 右子树（左根右，二叉搜索树中序遍历结果为有序序列）
  • 后序遍历（Post-order）：左子树 -> 右子树 -> 根节点（左右根）

广度优先遍历（BFS / 层序遍历） ​

按层从上到下、从左到右依次访问：

  • 核心实现机制：借助队列（Queue）。将根节点入队，进入 while(queue.length) 循环，出队并访问当前节点，依次将左右子节点推入队列中。

常见排序算法实现（纯函数标准实现） ​

TIP

日常开发与工程代码中，应避免在 Array.prototype 原型链上直接扩充方法，建议采用纯函数输入输出以确保健壮性。

1. 冒泡排序（Bubble Sort） ​

思路：依次比较相邻元素，若逆序则交换；每轮外层循环能保证当前最大数“浮”到末尾。平均时间复杂度 $O(n^2)$。

js
function bubbleSort(arr) {
  const result = [...arr];
  const len = result.length;
  for (let j = 0; j < len - 1; j++) {
    for (let i = 0; i < len - 1 - j; i++) {
      if (result[i] > result[i + 1]) {
        [result[i], result[i + 1]] = [result[i + 1], result[i]];
      }
    }
  }
  return result;
}

2. 选择排序（Selection Sort） ​

思路：每轮从未排序区间选出最小值的下标，与未排序区间的首位交换。时间复杂度 $O(n^2)$。

js
function selectionSort(arr) {
  const result = [...arr];
  const len = result.length;
  for (let j = 0; j < len - 1; j++) {
    let minIndex = j;
    for (let i = j + 1; i < len; i++) {
      if (result[i] < result[minIndex]) {
        minIndex = i;
      }
    }
    if (minIndex !== j) {
      [result[minIndex], result[j]] = [result[j], result[minIndex]];
    }
  }
  return result;
}

3. 插入排序（Insertion Sort） ​

思路：将数组看作有序和无序两部分，依次将无序区的首个元素插入到有序区合适位置。最好情况下（基本有序）时间复杂度 $O(n)$，平均 $O(n^2)$。

js
function insertionSort(arr) {
  const result = [...arr];
  for (let j = 1; j < result.length; j++) {
    const temp = result[j];
    let index = j;
    while (index > 0 && result[index - 1] > temp) {
      result[index] = result[index - 1];
      index--;
    }
    result[index] = temp;
  }
  return result;
}

4. 快速排序（Quick Sort） ​

思路：分治策略。选取一个基准值（Pivot），将小于基准的元素放左边，大于基准的元素放右边，再递归对子数组排序。平均时间复杂度 $O(n \log n)$。

js
function quickSort(arr) {
  if (arr.length <= 1) return arr;
  const base = arr[0];
  const left = [];
  const right = [];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] <= base) {
      left.push(arr[i]);
    } else {
      right.push(arr[i]);
    }
  }

  return [...quickSort(left), base, ...quickSort(right)];
}

二分查找（Binary Search） ​

前提条件：目标序列必须是有序数组。时间复杂度 $O(\log n)$。

js
function binarySearch(arr, target) {
  let low = 0;
  let high = arr.length - 1;

  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (arr[mid] === target) {
      return mid;
    } else if (arr[mid] < target) {
      low = mid + 1;
    } else {
      high = mid - 1;
    }
  }

  return -1;
}

四大算法设计思想 ​

  • 分而治之（Divide and Conquer）：将复杂原问题拆解成若干规模更小但结构相同的独立子问题，分别求解后再将子问题结果合并（如快速排序、归并排序）。
  • 动态规划（Dynamic Programming）：将原问题拆解成存在重叠子问题和最优子结构的子阶段，通过记忆化或递推（自底向上）避免重复计算（如背包问题、最长递增子序列）。
  • 贪心算法（Greedy Algorithm）：在求解问题的每一步都做出当前看似最佳的局部选择，期望最终达到全局最优（结果并不一定能得到全局最优解，需数学证明贪心选择性质）。
  • 回溯算法（Backtracking）：采用试探性的渐进式深度优先搜索策略，当探索到某一步发现不满足求解条件或无法得到解时，回退到上一步另选路径继续尝试（如八皇后问题、全排列）。
