vue3 报错:找不到模块或其相应的类型声明。（Vue 3 can not find module） ​

如果是自定义页面组件路径报错,在 src 目录下新建 global.d.ts 文件

js
declare module '*.vue'{
  import { ComponentOptions} from 'vue'
  export default const componentOptions: ComponentOptions
}

如果是第三方插件报错，在 src 或者根目录下新建 global.d.ts 文件:写入如下代码,xxx 为模块名。如果有多个模块报类似错误,则写多段以下代码

js
declare module 'xxx' {
  export const content: any
}

vue3+vite 项目中,实现自动注册路由 ​

1.下载 vite-plugin-pages

js
npm install -D vite-plugin-pages

2.在 vite.config.ts->defineConfig->plugins 里面写入

js
plugins: [
 // 如果写成Pages()，则等价于Pages({pagesDir: 'src/pages'});另外此处src不能写成@
 Pages({
  pagesDir: 'src/views'
 })
],

3.在 router/index.ts 中写入

js
import { createRouter, createWebHistory, RouteRecordRaw } from 'vue-router'
import routes from 'virtual:generated-pages' //关键代码
const router = createRouter({
  history: createWebHistory(),
  routes: routes, //关键代码
})
export default router

vue3 获取 dom 的两种方式 ​

通过 ref 或者 reactive 都可以实现获取 dom

vue
<template>
  <el-form ref="refForm"></el-form>
</template>
// 方式一
<script lang="ts">
import { defineComponent, reactive, toRefs } from 'vue'
export default defineComponent({
  name: 'Page',
  components: {},
  setup() {
    const state = reactive({
      refForm: null as any,
    })
    console.log(state.refForm)
    return {
      ...toRefs(state),
    }
  },
})
</script>
// 方式二
<script lang="ts">
import { defineComponent, reactive, toRefs } from 'vue'
export default defineComponent({
  name: 'Page',
  components: {},
  setup() {
    const refForm = ref()
    console.log(refForm.value)
    return {
      refForm,
    }
  },
})
</script>

vue3 中自动引入 ​

  1. unplugin-auto-import 主要作用：自动导入 API 函数、组合式函数等代码级别的导入。
  2. unplugin-vue-components 主要作用：自动导入和注册 Vue 组件。

使用步骤：

  1. 安装依赖
sh
pnpm add -D unplugin-auto-import unplugin-vue-components @types/node
  1. 配置 Vite 插件（vite.config.ts）
js
import AutoImport from 'unplugin-auto-import/vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  plugins: [
    // ... 其他插件
    AutoImport({
      // 自动导入 Vue 相关函数，如：ref, reactive, toRef 等
      imports: ['vue', 'vue-router'],
      // 解析 ElementPlus 组件
      resolvers: [ElementPlusResolver()],
      // 生成 TypeScript 声明文件
      dts: true,
      // 生成 eslint 配置文件
      eslintrc: {
        enabled: true,
      },
    }),
    Components({
      // 指定组件所在文件夹
      dirs: ['src/components'],
      // 组件的有效文件扩展名
      extensions: ['vue'],
      // 配置文件生成位置
      dts: 'src/types/components.d.ts',
      // 解析 ElementPlus 组件
      resolvers: [ElementPlusResolver()],
    }),
  ],
})
  1. 配置 TypeScript（tsconfig.json）
js
{
  "compilerOptions": {
    // ... 其他配置
    "types": ["node"],
    // 确保包含自动生成的类型文件目录
    "typeRoots": [
      "node_modules/@types",
      "src/types"
    ]
  },
  // 确保包含自动生成的声明文件
  "include": [
    "src/**/*.ts",
    "src/**/*.d.ts",
    "src/**/*.tsx",
    "src/**/*.vue",
    "auto-imports.d.ts"  // 自动导入的声明文件
  ]
}
  1. 配置 eslint（.eslintrc.js）
js
module.exports = {
  extends: [
    // ... 其他配置
    './.eslintrc-auto-import.json', // 自动生成的 ESLint 配置
  ],
  // ... 其他配置
}

现象:本地环境:点击新增按钮,打开弹窗,显示如下警告: Maximum recursive updates exceeded in component. This means you have a reactive effect that is mutating its own dependencies and thus recursively triggering itself. Possible sources include component template, render function, updated hook or watcher source function.线上环境:点击按钮,无法打开弹窗,页面直接卡死 原因:父组件给子组件传值的下拉框接口数据有问题,存在有 id，没有 name 的数据，导致页面渲染异常. 解决方法:过滤异常数据

vue 中使用带参数的 computed ​

有时候需要根据传入的参数,来决定返回值情况。此时,普通的计算属性无法满足,需要使用带参数的计算属性

js
// 定义时
const hasChild = computed(() => (row: any) => {
  const findIndex = tableData.value.findIndex((item: any) => item.fid === row.uid)
  if (findIndex !== -1) {
    return false
  } else {
    return true
  }
})

// 使用时
<el-table-column label="操作" align="center" show-overflow-tooltip>
  <template #default="{ row, $index }">
    <el-button v-if="hasChild(row)" type="primary" link @click="onDelete(row, $index)"
      >删除</el-button
    >
  </template>
</el-table-column>

vite 打包的项目取消生产环境中的 console 打印日志 ​

js
// vite.config.ts
import { defineConfig } from 'vite'
export default defineConfig({
  build: {
    terserOptions: {
      compress: {
        drop_console: true, // 这行代码会剔除掉所有的 console.* 函数调用
        drop_debugger: true, // 这行代码会剔除掉所有的debugger调用
      },
    },
  },
})

动态样式绑定的几种方式 ​

  1. 绑定对象
html
<!-- style绑定 -->
<div :style="{color: color, fontSize: size + 'px'}"></div>
<!-- class绑定 -->
<div
  :class="{
    oneStyle: formData.priorityId === 1,
    twoStyle: formData.priorityId === 2,
  }"
></div>
  1. 绑定数组
html
<!-- style绑定 -->
<div :style="[{color: color, fontSize: size + 'px'}]"></div>
<!-- class绑定 -->
<div
  :class="[
    formData.priorityId === 1 ? 'oneStyle' : '',
    formData.priorityId === 2 ? 'twoStyle' : '',
  ]"
></div>
  1. 在循环中动态绑定样式
html
<!-- 循环中动态绑定样式 -->
<!-- 语法一 -->
<div
  v-for="(item, index) in list"
  :key="index"
  :class="{'active': index === activeIndex}"
  @click="activeIndex = index"
>
  {{ item }}
</div>
<!-- 语法二 -->
<div
  v-for="(item, index) in list"
  :key="index"
  :class="index === activeIndex ? 'active' : ''"
  @click="activeIndex = index"
>
  {{ item }}
</div>

项目本地能正常访问，打包后使用 go live 本地起服务打不开 ​

可能是路由问题,将 history 路由模式改为 hash 模式即可

js
// history 模式
import { createRouter, createWebHistory, RouteRecordRaw } from 'vue-router'
const router = createRouter({
  history: createWebHistory(),
  routes,
})

// hash 模式

import { createRouter, createWebHashHistory, RouteRecordRaw } from 'vue-router'
const router = createRouter({
  history: createWebHashHistory(),
  routes,
})

项目本地能正常访问，打包后放服务器上打不开 ​

三种可能:

  1. vite 打包路径没有配好，即 base 的值

npm run build 命令没有指定特定的模式时 ​

在这种情况下,vue cli 会默认使用 production 模式。 Vue Cli 默认识别的生产环境配置文件为.env.production, 如果想要识别其他名称的生产环境配置文件如:.env.prod 或者.env.pro,需要在 package.json 中指定模式

sh
# .env.prod
"build:prod": "vue-cli-service build --mode prod"
# .env.pro
"build:pro": "vue-cli-service build --mode pro"

sourceMap 配置技巧 ​

  1. 在 vue.config.js 中配置:productionSourceMap 和 css 中的 sourceMap 为 true,然后 configureWebpack 中配置 devtool 为 hidden-source-map: 这样生产环境会生成 sourceMap,但是不会自动关联源码
js
module.exports = defineConfig({
  productionSourceMap: true,
  css: {
    sourceMap: true,
  },
  configureWebpack() {
    return {
      devtool: 'hidden-source-map',
    }
  },
})
  1. 在浏览器控制台的 sources 面板中右击选择 Add source map,手动添加 sourceMap 文件路径即可。可以用绝对路径也可以用相对路径。 如果打包后的文件路径为https://dev.furenyun.com/admin/js/6.js?v=1743474235161,则 sourceMap 文件路径为如下： 绝对路径：https://dev.furenyun.com/admin/js/6.js.map 相对路径：/admin/js/6.js.map

关于 ref 和 reactive 的使用 ​

写法一等价于写法二，不会丢失响应式,写法三会丢失响应式，写法四会报错。toRefs 只能和 reactive 搭配使用,不能和 ref 搭配使用

js
// 写法一
const obj = ref({})
const message = ref('')
// 等价于写法二

const { obj, message } = toRefs(
  reactive({
    obj: {},
    message: '',
  }),
)
// 不等价于写法三
const { obj, message } = ref({
  obj: {},
  message: '',
})
// 不等价于写法四
const { obj, message } = toRefs(
  ref({
    obj: {},
    message: '',
  }),
)

vue3 实现导出功能步骤 ​

前端导出

  1. 安装 xlsx 库
sh
npm install xlsx file-saver --save
  1. 导出函数
js
// 导出
const handleExport = () => {
  if (!tableData.value || tableData.value.length === 0) {
    ElMessage.warning('暂无数据可导出')
    return
  }

  // 使用CSV格式作为Excel的兼容格式
  const exportToCSV = () => {
    try {
      const headers = ['用户名', '角色', '创建时间', '描述']
      const rows = tableData.value.map((item: any) => [item.userName || '', item.roleStrs || '', item.createTime || '', item.description || ''])

      // 创建CSV内容
      const csvContent = [headers.join(','), ...rows.map((row) => row.map((cell) => `"${String(cell).replaceAll('"', '""')}"`).join(','))].join('\n')

      // 创建Blob并下载
      const blob = new Blob([`\uFEFF${csvContent}`], {
        type: 'text/csv;charset=utf-8;',
      })
      const a = document.createElement('a')
      const url = URL.createObjectURL(blob)
      a.href = url
      const date = new Date()
      const dateStr = `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}-${String(date.getDate()).padStart(2, '0')}`
      a.download = `用户列表_${dateStr}.csv`
      document.body.append(a)
      a.click()
      a.remove()
      URL.revokeObjectURL(url)

      ElMessage.success('导出成功')
    } catch (error) {
      console.error('导出失败:', error)
      ElMessage.error('导出失败，请检查控制台获取详细信息')
    }
  }

  // 尝试使用xlsx库导出真正的Excel文件
  try {
    import('xlsx')
      .then((XLSX) => {
        const excelData = tableData.value.map((item: any) => ({
          用户名: item.userName || '',
          角色: item.roleStrs || '',
          创建时间: item.createTime ? formatDateTime(item.createTime) : '',
          描述: item.description || '',
        }))

        const worksheet = XLSX.utils.json_to_sheet(excelData)

        // 设置列宽
        const cols = [
          { wch: 20 }, // 用户名
          { wch: 30 }, // 角色
          { wch: 20 }, // 创建时间
          { wch: 30 }, // 描述
          { wch: 10 }, // 状态
        ]
        worksheet['!cols'] = cols

        const workbook = XLSX.utils.book_new()
        XLSX.utils.book_append_sheet(workbook, worksheet, '用户列表')

        const excelBuffer = XLSX.write(workbook, {
          bookType: 'xlsx',
          type: 'array',
        })

        const blob = new Blob([excelBuffer], {
          type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
        })

        const a = document.createElement('a')
        const url = URL.createObjectURL(blob)
        a.href = url
        const date = new Date()
        const dateStr = `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}-${String(date.getDate()).padStart(2, '0')}`
        a.download = `用户列表_${dateStr}.xlsx`
        document.body.append(a)
        a.click()
        a.remove()
        URL.revokeObjectURL(url)

        ElMessage.success('导出成功')
      })
      .catch((error) => {
        console.warn('xlsx库加载失败，使用CSV格式导出:', error)
        exportToCSV() // 回退到CSV导出
      })
  } catch (error) {
    console.warn('导出异常，使用CSV格式导出:', error)
    exportToCSV() // 回退到CSV导出
  }
}

v-model 双向绑定的特殊用法 ​

代码中使用的 update:dialogVisible 是 Vue v-model 双向绑定的标准事件名称。当父组件使用 v-model:dialogVisible 绑定属性时，子组件通过 emit('update:dialogVisible', value) 可以自动更新父组件的绑定值

vue
<!-- 父组件 -->
<StepConfig v-model:dialogVisible="isVisible" />

<!-- 子组件 StepConfig.vue -->
<script setup>
// 定义可触发的事件
const emit = defineEmits(['update:dialogVisible'])

// 触发事件，关闭对话框
const closeDialog = () => {
  emit('update:dialogVisible', false) // 事件名 + 数据
}
</script>
