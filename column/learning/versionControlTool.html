nvm 下载与使用 ​

下载:搜索 git 仓库路径https://github.com/coreybutler/nvm-windows/releases，选择nvm-setup.exe下载安装即可 使用:xx.xx.x 为 node 版本号

  • 下载指定版本的 node
js
nvm install xx.xx.x
  • 使用指定版本的 node
js
nvm use xx.xx.x

如果 npm 切换了淘宝镜像地址,nvm 中也需要进行对应设置。打开 nvm 安装目录,找到 settings.txt 文件

sh
# 查询nvm安装目录
nvm root

添加两行:

sh
node_mirror: https://npmmirror.com/mirrors/node/
npm_mirror: https://npmmirror.com/mirrors/npm/

nrm 下载与使用 ​

nrm 是一个 npm 镜像源管理工具,可以方便地切换 npm 镜像源。

  • 安装 nrm
sh
npm install -g nrm
  • 查看可用的镜像源
sh
nrm ls
  • 切换镜像源
sh
# name 为镜像源名称,如 npm,taobao等
# 该命令默认切换的是 npm 镜像源
nrm use <name>
  • 获取包管理器的镜像源
sh
npm config get registry
yarn config get registry
pnpm config get registry
  • 设置包管理器的镜像源
sh
# url 为镜像源地址,如 https://registry.npmjs.org/
npm config set registry <url>
yarn config set registry <url>
pnpm config set registry <url>

npm 全局路径配置 ​

问题现象 ​

执行全局安装的命令（如 pnpm i）时报错：无法识别命令。

原因分析 ​

npm 全局安装路径未添加到系统环境变量 PATH 中，导致全局安装的包无法识别。

解决方案 ​

sh
# 1. 查看当前 npm 全局路径
npm config get prefix

# 2. 将 npm 全局路径改为 Windows 默认路径（推荐）
npm config set prefix "C:\Users\<用户名>\AppData\Roaming\npm"

# 或使用环境变量
npm config set prefix "%APPDATA%\npm"

# 3. 重新安装全局包
npm install -g pnpm

Windows npm 默认路径 ​

C:\Users\<用户名>\AppData\Roaming\npm

Windows 安装 Node.js 时，会自动将该路径添加到 PATH 环境变量。

配置说明 ​

  • npm 配置文件位置：C:\Users\<用户名>\.npmrc
  • 配置对 nvm 的所有 node 版本生效（用户级配置）
  • 使用默认路径后，切换任何 node 版本，全局包都可用，无需重新安装
sh
# 查看 npm 配置文件位置
npm config get userconfig

git 分支合并 ​

比如在 dev 分支上开发功能,开发完成后需要把所有内容推送到远程的 dev,并且合并到 test 分支上。使用 vscode 就可以完成全部操作。 步骤:

  1. 在本地 dev 分支上进行常规的提交和推送
  2. 在左下角切换到本地 test 分支上,点击 git 源代码管理按钮,点击...，选择分支选项, 选择合并,再选择要合并过来的本地 dev 分支
  3. zai 本地 test 分支上,进行常规的提交和推送即可

git 推送失败的解决方法:(22 端口连接超时) ​

一. 问题定位

  1. 测试 SSH 连接
sh
ssh -T git@github.com

结果 ：连接超时 ssh: connect to host github.com port 22: Connection timed out 2. 查看远程仓库地址

sh
git remote -v

结果 ：确认使用 SSH 协议连接 二. 解决方法

  1. 切换 SSH 连接端口到 443
sh
# 修改远程仓库URL为SSH 443端口格式
git remote set-url origin ssh://git@ssh.github.com:443/bft2249228496/vitepress-blog.git
  1. 创建 known_hosts 文件
sh
# 创建known_hosts文件
New-Item -ItemType File -Path .git\known_hosts -Force

# 获取GitHub主机密钥并添加到文件（Windows PowerShell）
ssh-keyscan -p 443 ssh.github.com | Set-Content -Encoding ASCII .git\known_hosts
  1. 配置 git 使用特定的 ssh 命令
sh
# 设置Git的SSH命令配置
git config core.sshCommand 'ssh -o UserKnownHostsFile=.git/known_hosts -o StrictHostKeyChecking=no -p 443'
  1. 测试链接
sh
# 测试SSH连接
ssh -T git@ssh.github.com -p 443

注意:另一种方法是全局修改 ssh 的 22 端口位 443： 找到.ssh 目录，创建 config 文件，写入以下内容：

sh
# GitHub 443 端口配置
Host github.com
  Hostname ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/id_rsa
  IdentitiesOnly yes
  # 如果你遇到警告，可以尝试添加以下行
  # StrictHostKeyChecking no
  # UserKnownHostsFile /dev/null
