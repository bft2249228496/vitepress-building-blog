微信开发者工具运行小程序项目后登录报错:http://xxx.xxx.xxx.com不在合法域名内 ​

原因：未开启微信开发者工具不校验合法域名 解决方法:点击详情-本地设置-勾选不校验合法域名

uniapp 项目使用 hbuilderx 以插件的方式导入 uview 步骤 ​

1.打开插件市场，搜索 uview，选择下载插件并导入 hbuilderx 2.main.js 中引用

js
import uView from "@/uni_modules/uview-ui";
Vue.use(uView);

3.uni.scss 中导入

css
@import "@/uni_modules/uview-ui/theme.scss";

4.在 APP.vue 以及所有的 vue 文件中 style 标签上加 scss

vue
<style lang="scss"></style>

java 环境变量配置(uniapp 本地打包 apk 生成证书签名的时候会用到) ​

JAVA_HOME 为 jdk 的实际安装路径，Path 和 CLASSPATH 的路径通用,直接复制即可

  1. JAVA_HOME：D:\Program Files\Java\jdk-1.8
  2. Path：①%JAVA_HOME%\jre\bin ②%JAVA_HOME%\bin
  3. CLASSPATH：.;%JAVA_HOME%\lib\dt.jar;%JAVA_HOME%\lib\tools.jar;

uniapp 打包成 APK 时,安装包安装不上,报错 ​

不同机型的 CPU 类型不同,需要在 manifest.json 文件中切换 APP 常用其他设置,勾选支持 CPU 类型:armeabi-v7a 和 arm64-v8a

uniapp 中使用 iData 条码扫描插件实现 PDA 扫描头扫描功能(将插件作为本地插件来使用) ​

  • 打开 uniapp 插件市场，搜索 iData 条码扫描插件，下载 for 离线打包，将插件解压放在 nativeplugins 文件夹下，再将文件夹放入 uniapp 项目的根目录里
  • 打开 manifest.json 文件，切换到 App 原生插件配置选项，找到本地插件，点击选择本地插件，导入刚刚的插件即可
  • 在需要使用插件的页面的 script 标签里引入
js
<script>
  const barcodeModel = uni.requireNativePlugin("iData-BarcodePlugin-BarcodeModule")
  const modal = uni.requireNativePlugin('modal');
  const globalEvent = uni.requireNativePlugin('globalEvent');
  export default {}
<script>
  • 在页面加载的时候初始化插件并添加全局监听事件
js
 onLoad() {
   // #ifdef APP-PLUS
    this.initPad();
    let that = this;
    globalEvent.addEventListener("iDataBarcodeEvent", that.pdaWatch);
    // #endif
  }
  methods: {
    // 初始化扫描
    initPad() {
    barcodeModel.initScan((ret) => {
      console.log('初始化扫描' + JSON.stringify(ret))
    });
   },
    // 扫描处理事件
    pdaWatch(e) {
    console.log(JSON.stringify(e));
        const url = e?.barcode
   }
  }
  • 在页面卸载的时候关闭扫描头并全局移除事件
js
 onUnload() {
   // #ifdef APP-PLUS
    let that = this;
    barcodeModel.closeScan((ret) => {
      console.log(ret);
    });
    globalEvent.removeEventListener("iDataBarcodeEvent", that.pdaWatch)
    // #endif
  },
  • 在需要打开扫描头的地方绑定点击事件
js
 clickPda() {
    barcodeModel.scanStart((ret) => {
      console.log('开始扫描' + JSON.stringify(ret))
    }
  }

uniapp 项目云打包成 APP 步骤 ​

  1. 打开 manifest.json 文件,切换 APP 常用其他设置,勾选支持 CPU 类型:armeabi-v7a 和 arm64-v8a
  2. 打开 hbuilderx，选中当前项目,点击发行-原生 App 云打包,选择使用云端证书,xz 快速安心打包
  3. 控制台找到安装包所在目录即可

电脑给安卓手机或者 pda 安装 apk 安装包的方法 ​

方法一:使用 360 手机助手安装或者微信,qq 来实现安装 方法二:使用 adb 来安装：

  1. 下载 adb：https://dl.google.com/android/repository/platform-tools-latest-windows.zip：解压到任意目录， 例如放在 D:\Program> Files 文件夹下面， 这样 adb 的目录就是 D:\Program Files\platform-tools
  2. 配置 adb 环境变量：此电脑->系统属性->高级系统设置->环境变量->系统变量->path->新建->输入 adb 目录。终端输入 adb --version,验证是否成功
  3. 使用命令进行安装 apk 文件:adb install D:\APKlxb\simpleDemo-release.apk 注意：如果电脑中已有 Android Studio,则不需要下载 adb,只需要配置环境变量即可 环境变量也可以这样配置： adb_home:C:\Users\user\AppData\Local\Android\Sdk\platform-tools path:%adb_home%

uniapp 进行离线打包 APP 时报错 ​

错误提示：xx 项目导出失败。这是因为 node 版本不对,uniapp 项目打包时需要切换成和项目运行时相同的 node 版本

uniapp 中的弹窗 uToast ​

uToast 同时只会存在一个,代码中如果同时写了多次触发条件,后面触发的弹窗的会覆盖前面的,前面的弹窗不再触发。以下代码只会触发第二个弹窗。

js
const fun = () => {
  this.$refs.uToast.show({
    title: "请扫描正确的二维码",
    type: "error",
  });
  this.$refs.uToast.show({
    title: "请扫描正确的二维码2",
    type: "error",
  });
};

安卓 modal 弹窗 ​

该 modal 附带 return 功能，一旦触发会终止函数,阻止后续代码运行。以下代码中打印语句不再执行。

js
const fun = () => {
  modal.toast({
    message: "收到条码：" + JSON.stringify(e),
    duration: 1.5,
  });
  console.log("aaa");
};

uniapp 打包 apk,安装后提示打包时未添加 oauth 模块 ​

解决方法是找到 manifest.json,切换到 APP 权限配置,勾选 OAuth 登录鉴权(不要勾选子选项),重新打包即可

uniapp 打包 apk,安装后提示:不匹配的版本可能造成应用异常 ​

如本应用使用 HBuilderX 3.1.12 或对应的 cli 版本编译，而手机端 SDK 版本是 3.1.13，不匹配的版本可能造成应用异常

解决方法是在 manifest.json 文件的源码视图中配置忽略这个提醒

js
"app-plus": {
    "compatible": {
        "ignoreVersion": true //true表示忽略版本检查提示框，HBuilderX1.9.0及以上版本支持
    },
},

uniapp 打包 apk,含有 tabBar 的页面底部会有一段留白区域 ​

解决方法,找到 pages.json 里面的 tabBar 配置,将 height 改为 2rpx 即可

js
 "tabBar": {
    "custom": true,
    "color": "#909090",
    "selectedColor": "#5470c6",
    "borderStyle": "black",
    "backgroundColor": "#ffffff",
    "iconWidth": "32rpx",
    "fontSize": "24rpx",
    "height": "2rpx", //关键代码
    "list": [
      {
        "pagePath": "pages/preview/index"
      },
      {
        "pagePath": "pages/about/me"
      }
    ]
  }
}

uniapp 打包自定义基座到安卓设备 ​

  1. 数据线连接电脑和安卓设备,打开安卓设备的 USB 调试功能,USB 功能仅充电改为传输文件
  2. 打开 hbuilderx,点击运行到手机或模拟器,点击制作自定义调试基座,进入到打包页面
  3. 在打包页面勾选使用云端证书,打自定义调试基座和传统打包,点击打包即可
  4. 打包完成后,再次点击运行到手机或模拟器,点击运行到 Android App 基座
  5. 运行完成之后会在安卓设备上提示是否允许安装(第一次会提示),同意即可完成安装 注意: 基座包和正式包不能同时存在同一个设备上,每次更改完代码如果不报错会自动更新基座包(安卓设备表现为自动退出软件再重新进入),如果报错提示运行已停止,则需要删除基座包重新运行

uniapp 打包自定义基座时提示自定义基座版本和上次版本相同，将会导致运行到手机时不会自动更新基座 ​

修改版本号方法：打开 manifest.json 文件,在基础配置中修改应用版本名称和应用版本号即可

vue3 版本的 uniapp 项目报错:找不到模块“vue”或其相应的类型声明 ​

解决方法：在 tsconfig.json 文件中添加 types 选项数组中添加 node

js
"compilerOptions": {
  ...
  "types": ["node"]
}

vue3 版本的 uniapp 项目报错:找不到模块“uni”或其相应的类型声明 ​

解决方法：在 tsconfig.json 文件中添加 globals 选项数组中添加 uni 为 true

js
  globals: {
    uni: true, //关键代码
    wx: true
  }

uniapp 中音频方法 ​

需要注意的是所有方法执行时都是不带 on 的,只有监听时才带 on

js
const innerAudioContext = uni.createInnerAudioContext();
const clickPlay = () => {
  innerAudioContext.play(); //开始播放
};
const clickPause = () => {
  innerAudioContext.pause(); //暂停播放
};

/* 监听 */
onLoad(() => {
  innerAudioContext.onPlay(() => {
    console.log("监听播放");
  });
  innerAudioContext.onPause(() => {
    console.log("监听暂停");
  });
});

uniapp 运行到微信小程序报错[plugin:uni:mp-inject] ​

报错信息:[plugin:uni:mp-inject] Unexpected token 原因:对应文件使用(obj.xxx as any).xx 语法 解决方法:改成常规用法 obj.xxx.xx

uniapp 运行到微信小程序 axios 报错 ​

现象:h5 端正常，小程序端报错. There is no suitable adapter to dispatch the reque…ment-adapter http is not available in the build

原因:小程序默认不支持 axios,需要添加 axios 适配器 解决方法:

  1. 安装适配器库:
js
npm install axios-miniprogram-adapter
  1. 配置 Axios 适配器:
js
import axios from "axios";
import mpAdapter from "axios-miniprogram-adapter";
// 设置小程序适配器
axios.defaults.adapter = mpAdapter;

uniapp 项目运行到微信小程序样式丢失 ​

对样式库使用:deep 时,:deep 必须在最外层,否则运行到微信小程序时不生效

css
/* 生效 */
.content {
  height: calc(100vh - 88rpx);
  padding: 20rpx;
  display: grid;
  grid-template-rows: repeat(4, 1fr);
  grid-template-columns: repeat(2, 1fr);
}
:deep(.uni-card) {
  display: grid;
  grid-template-rows: 2fr 3fr;
  row-gap: 20rpx;
  padding: 20rpx !important;
}
/* 不生效 */
.content {
  height: calc(100vh - 88rpx);
  padding: 20rpx;
  display: grid;
  grid-template-rows: repeat(4, 1fr);
  grid-template-columns: repeat(2, 1fr);
  :deep(.uni-card) {
    display: grid;
    grid-template-rows: 2fr 3fr;
    row-gap: 20rpx;
    padding: 20rpx !important;
  }
}

uniapp 项目运行到微信小程序 v-show 不生效 ​

h5 端正常,小程序端不生效可能是 v-show 放在了自定义组件上，需要使用 view 标签包裹组件, 将 v-show 指令放到 view 标签上(不可以使用 text 标签包裹,会使组件不显示)

js
// 正确写法
<view v-show="!play">
  <u-icon size="40" name="pause-circle-fill"></u-icon>
</view>
<view v-show="play">
  <u-icon size="40" name="play-circle-fill"></u-icon>
</view>
// 错误写法1
<u-icon v-show="!play" size="40" name="pause-circle-fill"></u-icon>
<u-icon v-show="play" size="40" name="play-circle-fill"></u-icon>
// 错误写法2
<text v-show="!play">
  <u-icon size="40" name="pause-circle-fill"></u-icon>
</text>
<text v-show="play">
  <u-icon size="40" name="play-circle-fill"></u-icon>
</text>

uniapp 中使用媒体方法 uni.createInnerAudioContext()时运行到小程序端异常 ​

h5 端正常,微信小程序端无法获取 audio 文件的时长 duration。因为小程序端不支持 onCanplay 里面获取 duration, 需要在 onTimeUpdate 里面获取 duration

js
// h5端
innerAudioContext.onCanplay(() => {
  max.value = duration.value = Math.floor(innerAudioContext.duration);
  if (max.value) {
    if (!sliderSetIntervalFlag) {
      sliderSetInterval();
    }
  }
});
// 小程序端
innerAudioContext.onTimeUpdate(() => {
  if (!max.value) {
    max.value = duration.value = Math.floor(innerAudioContext.duration);
    sliderSetInterval();
  }
});

uniapp 打包到微信小程序平台获取数据失败 ​

原因:接口协议未 http,小程序只支持 https 协议的接口 解决:如果是体验版,上传之前勾选不校验合法域名,上传之后打开调试模式,即可正常调用接口。如果是正式版,只能购买安全证书,将协议升级为 https。

uniapp 项目运行到微信小程序报错[project.config.json 文件内容错误] ​

报错信息:project.config.json: libVersion 字段需为 string, string 解决方法:在 manifest.json 文件里面添加 libVersion:latest

js
  "mp-weixin" : {
        "libVersion":"latest",
    },

uniapp 中跳转外部链接适配多端的写法 ​

通过条件编译实现对 h5,小程序以及 app 端的不同处理,item.mobilUrl 为实际地址路径

js
// 跳转外部链接
const clickItem = (item: Data) => {
  // #ifdef APP-PLUS
  if (typeof plus !== "undefined") {
    plus.runtime.openURL(item.mobilUrl); //这里默认使用外部浏览器打开而不是内部web-view组件打开
  }
  // #endif
  // #ifdef H5
  window.open(item.mobilUrl);
  // #endif
  // #ifdef MP
  if (inWhiteList.value) {
    //如果在小程序的网址白名单中，会走内置webview打开，否则会复制网址提示在外部浏览器打开
    uni.navigateTo({
      url: "/pages/component/web-view/web-view?url=" + item.mobilUrl,
    });
  } else {
    uni.setClipboardData({
      data: item.mobilUrl,
    });
    uni.showModal({
      content:
        "本网址无法直接在小程序内打开。已自动复制网址，请在手机浏览器里粘贴该网址",
      showCancel: false,
    });
  }
  // #endif
};

uniapp 项目打包成安卓 apk 时,启动速度特别慢 ​

每次打开,其他端正常速度,app 端首页启动速度 10 秒以上。 解决方法:打开 manifest.json 文件,切换到 APP 启动界面，找到启动界面选项,将等待首页渲染完毕厚再关闭 Splash 图取消勾选即可

uniapp 中 pages.json 文件关键配置项 ​

  1. navigationStyle: 导航栏样式,默认值为 default,可选值: custom.设置 custom 即取消默认的原生导航栏，使用自定义导航栏

uniapp 中开启下拉刷新的方法 ​

  1. 在 pages.json 文件里面,找到需要开启下拉刷新的页面,在 style 里面添加 enablePullDownRefresh: true
  2. 在页面里面添加 onPullDownRefresh() 方法,在方法里面写需要执行的代码(一般是刷新列表的接口调用)

uniapp 云打包成安卓 apk 包时,部分电脑会卡死在编辑成功后,无法继续打包 ​

解决方案：将打包页面的快速安心打包改成传统打包即可

uniapp 项目中，ios 设备使用扫码和安卓设备扫码，数据不一致 ​

ios 设备扫码完成后，会自动激活一次 onShow 钩子函数,导致接口又被调用了一次

小程序线上版本回退 ​

如果小程序最新线上版本有问题,可以在管理后台找到版本管理，选择线上版本回退，可回退至线上已发布的最近 5 个版本，不用审核

扫码登录微信公众平台提示需要密码 ​

可以先登录自己有权限的小程序,再去切换成需要密码的小程序

从hbuilderx点发布到微信小程序失败，您不是这个应用的项目成员: ​

第一步：重新生成你自己的 DCloud AppID 在编辑器中打开 📁

manifest.json。 找到第 3 行： json "appid" : "**", 将该值修改为空字符串（或者直接删除这一行）： json "appid" : "", 或者你可以双击打开 manifest.json 的可视化视图 -> 选择 「基础配置」 -> 点击 AppID 旁边的 「重新获取」 按钮，它会自动为你当前的 DCloud 账号生成一个新的 ID。 第二步：重新运行「发行」 修改并保存 manifest.json 后，在 HBuilderX 顶部菜单栏重新点击 「发行」 -> 「小程序 - 微信」。 这次 HBuilderX 会一路绿灯编译成功，并在编译时剔除 vendor.js 中的调试信息并进行混淆压缩（体积会从 2.29MB 瞬间缩减到 300KB 左右）。 第三步：在微信工具中导入 build 包 编译成功后，打开微信开发者工具。 重新导入项目，将路径指向发行后的包：unpackage/dist/build/mp-weixin。 此时查看依赖分析，你的主包体积应该在 600KB - 900KB 左右，远低于 2MB 限制，不管是真机调试还是直接点击右上角「上传」发布，都不会再有任何体积报错！
