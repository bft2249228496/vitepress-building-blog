Vue 动态组件 ​

将 :is 与组件名称或组件对象进行绑定，即可通过切换数据动态渲染不同组件：

vue
<component :is="currentComponent"></component>

配合 <keep-alive> 可以在切换时缓存组件实例与状态：

vue
<keep-alive>
  <component :is="currentComponent"></component>
</keep-alive>

Vue 移动端适配与注意事项 ​

1. 视口 Meta 标签配置 ​

在 public/index.html 的 <head> 中配置标准 Viewport：

html
<meta
  name="viewport"
  content="width=device-width, initial-scale=1.0, minimum-scale=1.0, maximum-scale=1.0, user-scalable=no"
/>

2. 基础样式与 1px 物理像素边框 ​

  • 抹平各浏览器默认样式：在 main.js 中引入 reset.css 或 normalize.css。
  • 解决 Retina 屏幕移动端 1px 细线变粗问题：通过 ::after 伪元素设置绝对定位 + transform: scaleY(0.5) 模拟。

3. 移动端 300ms 点击延迟处理（演进与现状） ​

IMPORTANT

历史方案与现代淘汰说明：

  • 早期方案：过去常使用 fastclick 插件拦截 touchstart/touchend 消除延迟（import fastClick from 'fastclick'; fastClick.attach(document.body);）。
  • 现代标准推荐：现代移动端（Chrome 32+、iOS 9.3+）已完全无需使用 fastclick！只要配置了 <meta name="viewport" content="width=device-width"> 或者对需要快速响应的交互元素设置 CSS touch-action: manipulation;，现代浏览器原生就会禁用双击缩放手势并消除 300ms 延迟。在现代 iOS 上继续使用 fastclick 反而会导致输入框无法聚焦、点击穿透等严重兼容 Bug。

npm install -g @vue/cli

vue create my-project

模板中事件同时触发多个方法 ​

在 Vue 模板中，@click 等内联事件处理器支持用分号 ; 或逗号 , 串联执行多个函数或表达式：

vue
<!-- 内联多个执行语句用分号分隔 -->
<div @click="arrowFun(); drawer = !drawer"></div>

<!-- 或依次调用多个带括号的函数 -->
<button @click="handleClick(), trackEvent()"></button>
