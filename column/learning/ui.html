表格里的 el-select 的数据 option 如果是每次选择后动态过滤已选择的数据导致数据回显异常 ​

因为过滤已选中数据的原因，回显的时候 value 对应的值实际上已经从 option 里面过滤掉了,无法根据 value 回显对应的 label，就会直接显示成 value 处理思路:直接存两份数据，一份保存过滤前的原始数据 originOption,一份保存过滤后的数据 filterOption;每次下拉框隐藏的时候将 option 赋值为 filterOption，每次回显的时候讲 option 赋值为 originOption

elementUI 中 el-dropdown 组件中的@command 方法优化 ​

因为子组件 el-dropdown-menu 的 command 属性值可以为字符串、数值、对象,可以将 command 属性设为一个对象,将函数作为该对象的方法传入,然后在父组件 el-dropdown 组件中的@command 方法里面直接调用传入对象的方法,即可实现子方法的映射，省去了 if 或者 switch 的这种条件判断

html
<el-dropdown @command="(command) => handleOperationFun(command, row)">
  <el-button
    link
    type="primary"
    >操作</el-button
  >
  <template #dropdown>
    <el-dropdown-menu>
      <el-dropdown-item :command="{ command: handleWithdraw }">
        <el-button
          link
          type="default"
        >
          <el-icon><Document /></el-icon>
          撤回
        </el-button>
      </el-dropdown-item>
      <el-dropdown-item :command="{ command: handleCancel }">
        <el-button
          link
          type="default"
        >
          <el-icon><Document /></el-icon>
          取消
        </el-button>
      </el-dropdown-item>
      <el-dropdown-item :command="{ command: handleDelete }">
        <el-button
          link
          type="default"
        >
          <el-icon><Document /></el-icon>
          删除
        </el-button>
      </el-dropdown-item>
    </el-dropdown-menu>
  </template>
</el-dropdown>
js
// 操作按钮
const handleOperationFun = (command: any, row: any) => {
  console.log(command, row, '操作')
  command.command(row)
}
// 撤回按钮
const handleWithdraw = () => {
  console.log('撤回')
}

// 取消按钮
const handleCancel = () => {
  console.log('取消')
}

// 删除按钮
const handleDelete = (row?: any) => {
  console.log('删除', row)
}

表格中的表单校验 ​

表格中进行表单的自定义校验,并且将表格中当前行的数据作为额外参数传递给自定义校验函数。 关键点：

  1. dom 中结构层级为 el-form>el-table>el-table-column>template>el-form-item
  2. el-table 中 data 绑定的值必须是 el-form 中 model 绑定的对象的属性
  3. el-form-item 中的 prop 属性写成动态变量,三部分拼接而已:model 绑定值的对象的属性名(如 tableDate) + 表格行的序号{$index} + rules 对象中对应的属性名(如 start)
  4. el-form-item 中需要再添加 rules 属性,绑定的值为 rules 的对应属性(如 rules.start)
  5. 表格行 template 里面的具体组件 v-model 的绑定值需要和当前 el-form-item 中 prop 和 rules 绑定的属性名保持一致(如 row.start)
  6. 传递额外参数时：直接在 el-form-item 里面的 rules 绑定的变量 rules.start 的值改成函数返回数组的形式,dom 上写成 rules.start(row)即可传递表格当前行的参数 row 到函数 startValidateFun 里;startValidateFun 函数里面的大致写法为 const startValidateFun = (row: any) => { return [ { required: true, validator: (rule: any, value: any, callback: any) => validatePass(rule, value, callback, row), trigger: 'change' } ] }

setup() {
   const validatePass = (rule: any, value: any, callback: any, row: any) => {
      if (value) {
        const start = new Date(value).getTime()
        const end = new Date(row.end).getTime()
        if (start > end) {
          callback(new Error('开始时间不能大于结束时间'))
        } else {
          callback()
        }
      } else {
        callback(new Error('请选择时间'))
      }
    }
    const validatePass1 = (rule: any, value: any, callback: any, row: any) => {
      if (value) {
        const start = new Date(row.start).getTime()
        const end = new Date(value).getTime()
        if (start > end) {
          callback(new Error('结束时间不能小于开始时间'))
        } else {
          callback()
        }
      } else {
        callback(new Error('请选择时间'))
      }
    }
     const startValidateFun = (row: any) => {
      return [
        {
          required: true,
          validator: (rule: any, value: any, callback: any) => validatePass(rule, value, callback, row),
          trigger: 'change'
        }
      ]
    }
    const endValidateFun = (row: any) => {
      return [
        {
          required: true,
          validator: (rule: any, value: any, callback: any) => validatePass1(rule, value, callback, row),
          trigger: 'change'
        }
      ]
    }
     const state = reactive({
      formData: {
        tableData: []
      },
       rules: {
        start: startValidateFun,
        end: endValidateFun,
        num: [{ required: true, trigger: 'blur', message: '请输入数量' }],
      } as any,
     })
  return {
    ...toRefs(state),
  }
}

elementPlus 组件库中的多个日期时间选择器 el-date-picker 组件禁用指定时间 ​

如用两个组件对开始时间和结束时间进行限制: 开始和结束时间不能大于当前时间,开始时间需要小于结束时间,开始时间和结束时间的跨度不能超过 31 天。 普通的 getTime()比较会让开始时间和结束时间是同一天的情况无法选中，需要通过 setHours(0,0,0,0)来实现

js
<el-form-item label="开始时间:" prop="startTime" class="!mb-0">
  <el-date-picker
    v-model="dialogForm.startTime"
    type="datetime"
    clearable
    placeholder="请选择"
    format="YYYY-MM-DD HH:mm:ss"
    value-format="YYYY-MM-DD HH:mm:ss"
    :disabled-date="disabledDateStart"
  />
</el-form-item>
<el-form-item label="结束时间:" prop="startTime" class="!mb-0">
  <el-date-picker
    v-model="dialogForm.endTime"
    type="datetime"
    clearable
    placeholder="请选择"
    format="YYYY-MM-DD HH:mm:ss"
    value-format="YYYY-MM-DD HH:mm:ss"
    :disabled-date="disabledDateEnd"
  />
</el-form-item>
// 开始时间禁用
const disabledDateStart = (time: Date) => {
  if (dialogForm.value.endTime) {
    return (
      time.setHours(0,0,0,0) > new Date(dialogForm.value.endTime).setHours(0,0,0,0) ||
      new Date(dialogForm.value.endTime).getTime() - time.getTime() > 1000 * 60 * 60 * 24 * 31
    )
  }
}
// 结束时间禁用
const disabledDateEnd = (time: Date) => {
  if (dialogForm.value.startTime) {
    return (
      time.setHours(0,0,0,0) < new Date(dialogForm.value.startTime).setHours(0,0,0,0) ||
      time.getTime() > new Date().getTime() ||
      time.getTime() - new Date(dialogForm.value.startTime).getTime() > 1000 * 60 * 60 * 24 * 31
    )
  }
}

elementPlus 组件库中对于 ElMessageBox.confirm 组件的封装 ​

默认情况点确认执行后续操作,点取消不作处理并终止函数。 如果需要对取消也进行操作,常规封装无法实现，需要再套一层 promise 对象。

// 删除窗体(常规窗体定义,不需要对取消额外操作)
    delConfirm(content?: string, tip?: string) {

        content ? content : t('common.delMessage'),
        tip ? tip : t('common.confirmTitle'),
        {
          confirmButtonText: t('common.ok'),
          cancelButtonText: t('common.cancel'),
          type: 'warning'
        }
      )
    },
    // (常规窗体调用)
    delConfirm()

 // 删除窗体(特殊窗体定义,需要对取消额外操作)
    delConfirmLater(content?: string, tip?: string) {
      return new Promise((resolve, _reject) => {
        const instance = ElMessageBox.confirm(
          content ? content : t('是否删除,删除将在保存后生效?'),
          tip ? tip : t('common.confirmTitle'),
          {
            confirmButtonText: t('common.ok'),
            cancelButtonText: t('common.cancel'),
            type: 'warning'
          }
        )
        instance
          .then(() => {
            resolve('confirm') // 用户点击确认
          })
          .catch(() => {
            resolve('cancel') // 用户点击取消
          })
      })
    },

el-table 组件中如果是带复选框的表格,selectable 属性无法禁用表头列的复选框 ​

解决方案:不使用 selectable 属性,直接控制复选框列的显示或隐藏

js
<ElTableColumn
  type='selection'
  width='55px'
  v-if='state.isShowSelect'
/>

el-table 组件中，执行 clearSelection();会触发复选框列的 change 事件 ​

解决方案: 监听 change 事件,在事件中判断是否是 clearSelection 触发的,如果是,则不执行后续操作

js
// 在组件中定义标志位
const ignoreSelectionChange = ref(false);

// 创建清除选择的方法
const clearSelectionSilently = () => {
  ignoreSelectionChange.value = true;
  tableRef.value?.clearSelection();

  // 确保在下一个事件循环中重置标志
  nextTick(() => {
    ignoreSelectionChange.value = false;
  });
};

// 监听选择变化事件
const handleSelectionChange = (selection) => {
  // 如果标志为 true，则忽略此次事件
  if (!ignoreSelectionChange.value) {
    // 正常的业务处理
    console.log('Selection changed:', selection);
  }
};

// 在模板中使用
<el-table
  ref="tableRef"
  @selection-change="handleSelectionChange"
  <!-- 其他属性 -->
>
  <!-- 表格列 -->
</el-table>

.demo-form-inline :deep(.el-form) {
  margin-bottom: 0 !important;
